#  Интерактивная модель Солнечной системы

Веб-приложение, моделирующее движение планет Солнечной системы с соблюдением физических пропорций расстояний (в А.Е.) и размеров небесных тел согласно ТЗ.

##  Функционал
*  **Умный зум:** масштабирование колесиком мыши строго в точку курсора + ползунок масштаба.
*  **Интерактивная справка:** при наведении мыши на планету отображается расстояние, радиус и орбитальная скорость.
*  **Космический календарь:** уникальный счетчик времени, рассчитывающий прожитые местные сутки и годы для каждой планеты на основе земного времени.
*  **Управление временем:** ползунок изменения скорости симуляции и кнопка «Пауза».

##  Технологии
* **Backend:** Python (Flask)
* **Frontend:** HTML5 Canvas, CSS3, JavaScript

##  Как запустить проект локально

1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Запустите сервер:
   ```bash
   python app.py
   ```
3. Откройте в браузере адрес: `http://127.0.0`
